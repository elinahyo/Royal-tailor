# 왕실 수선소 — 기획 진행상황 공유

## 현재 진행상황

**기준일: 2026-11-06 (한국 시간)**  
왕실 수선소의 Figma 전체 워크플로우 **v1.4**와 개발·디자인 협업 상세 기획 **v0.1**을 작성했습니다.

현재 완료 범위는 **기획 문서, 편집 가능한 화면·맵 배치도, 일부 화면 상태의 클릭 연결**입니다. 이번 작업에서 Unity 게임 구현, 최종 3D 에셋 제작, 실기기 플레이 테스트는 진행하지 않았습니다.

## 확정된 기획 방향

- 모바일 싱글플레이.
- 독립 튜토리얼: 정규 60개 맵과 별 평가에서 제외.
- 아래 5개 에피소드는 각각 12개 맵, 총 60개 맵이며 정규 맵당 최대 5성.
- 아트 방향: **A. 따뜻한 동화책 스타일 — 파스텔·둥근 로우폴리 3D**.
- AppLovin MAX 선택형 보상 광고와 게스트/선택 로그인 흐름 유지.
- ‘보이지 않는 옷’ 엔딩 구성은 포함하지 않음.

## 기존 문서와 맞춘 사항

- 기존 60맵 기획의 EP01-01 ‘통합 튜토리얼’ 표기를 **학습한 공정을 독립 수행하는 첫 정규 평가 맵**으로 수정했습니다.
- EP01-01의 기존 목표인 **2분 안에 정확한 셔츠 1벌 납품**을 유지했습니다.
- 모바일 싱글플레이·광고 보상·게스트/로그인 흐름을 유지했습니다.
- 기존 워크플로우에서 새 상세 기획으로 이동할 수 있는 링크를 추가했습니다.
- 로그인 출시 범위와 계정 연결 권유 시점의 서로 다른 표현을 아래 **제안안**으로 정리했습니다.

## 검토가 필요한 제안값

다음 내용은 최종 합의나 플레이 테스트를 마친 확정값이 아닙니다.

| 항목 | 현재 제안 |
|---|---|
| 화면·입력 | 가로 화면·고정 탑다운·왼손 이동/오른손 행동 |
| 기본 작업 규칙 | 소지 1개, 수작업 이탈 시 중단, 재봉 자동 진행 |
| 튜토리얼 | 건너뛰기·다시 배우기·마지막 완료 단계 복구 |
| 첫 맵 작업 시간 | 재단 3초 / 재봉 5초 |
| 첫 맵 별 문턱값 | 100 / 125 / 150 / 170 / 185점 |
| 제작·출시 순서 | 튜토리얼+첫 맵 검증 → EP01 3맵 MVP → EP01 12맵 → 후속 에피소드 |
| 계정 | MVP 게스트, 로그인·클라우드 백업 2차 |
| 연결 권유 | 로그인 기능 출시 후 EP01-12 첫 1성 이상 완료 시 1회 |
| 기기·아트 예산 | 목표 기기 및 메시·텍스처·메모리 예산은 개발·3D 담당자 검토 필요 |

## 확인한 사항

## 다음 개발 순서

1. **기획·개발·디자인:** 위 제안값 중 화면 방향·기본 조작·첫 구현 범위·목표 기기를 검토합니다.
2. **개발:** TUT-01과 EP01-01을 임시 모델로 구현합니다. 이동 → 집기 → 재단 → 자동 재봉 → 납품 → 결과까지 한 판을 완성합니다.
3. **개발·QA:** 로컬 저장, 결과 중복 정산, 광고 성공/실패/중복 콜백, 일시정지·앱 복귀를 검증합니다.
4. **디자인·기획:** 실기기에서 손가림·화면비·영어 문구·공정 구분을 확인하고 작업 시간과 별 문턱값을 조정합니다.
5. **공동:** 첫 맵 검증 후 EP01-02~03으로 확대합니다.

담당자의 실명과 일정은 아직 배정하지 않았습니다.
