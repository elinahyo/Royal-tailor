## 수정한 내용

| 부족했던 부분 | A03에서 바꾼 내용 |
|---|---|
| 메뉴·정보 카드가 게임 세계보다 앞섬 | 공방 전체 배경, 주문판·연습책 진입점, 원형 도구 버튼, 실로 이어진 지도 |
| 행동이 받아들여졌는지 불명확 | 눌림 상태, 원단 팝, 손에 든 물건 표시, 가까운 작업대 강조 |
| 제작 진행과 완료 반응이 약함 | 작업대 위 실 진행바, 가위·바늘 움직임, 완료 체크, 다음 목적지 |
| 납품과 점수·별의 관계가 약함 | 칭찬 → 점수 이동 → 별 도달 → 결과 화면의 순차 등장 |
| 결과가 정적이고 다음 목표가 약함 | 별 0.25/0.49/0.73초, 코인0.95초, 다음 주문1.6초 순서 |
| 로딩·실패가 경험을 끊음 | 천 전환, 실제 준비 조건, 실패 이유와 수정 행동, 차분한 재도전 피드백 |
| 사운드·진동·효과 처리 기준이 없음 | 발생·중단·중복 방지·우선순위·효과 감소 규칙과 음원 견본 |

아트는 A02의 단순한 파스텔 로우폴리를 유지합니다. 장식 밀도나 모델링 복잡도를 높여 해결하지 않았습니다. 기존 모바일 싱글플레이, 독립 튜토리얼, 5에피소드×12맵, 최대5성, 게스트/선택 로그인, AppLovin MAX 조건도 유지합니다.

## 이번 산출물

- 편집 가능한 핵심 UI **48개 상태**. 같은 화면의 제작·오류·보상·접근성 상태를 포함합니다.
- 실제 Figma 노드에 기록된 **205개 모션 트랙**, 모션을 가진 노드132개.
- 목차를 포함한 **268개 화면 이동 연결**, 주요 버튼 **21개의 누름 상태**, 검토 시작점8개.
- 5개 에피소드 지도에 총60개 맵 표시.
- 합성 효과음15종과 BGM 견본1종, 동기화 믹스1개, 실제 Figma 렌더에 소리를 합친5.2초 영상.
- Figma 네이티브 Spec 문서와 [동일한 구현 명세의 저장소 사본](../art/feedback/a03/game-feel-spec.md).

기존 A02 페이지는 흐름·서비스 예외 기록으로 남겼고 최신 A03 링크를 추가했습니다. 원래 시스템 워크플로우와 통합 v2.0 페이지의 디자인 바로가기도 A03으로 갱신했습니다.

## 확인한 범위

- 48개 프레임의 존재·크기, NanumGothic 글꼴, 텍스트 화면 경계, UI와 이미지 레이어 분리를 확인했습니다.
- 268개 저장된 이동 목적지에 누락이 없는지 확인하고 대표 흐름을 추적했습니다.
- 공방→조끼2벌 제작·납품→별·코인→해금, 독립튜토리얼, 시간연장, 광고코인, 잘못된원단 교체, 재도전 경로를 확인했습니다.
- 5개 지도에 각각12개 맵이 있는지 대조했습니다.
- 납품·결과를 실제 Figma 타임라인 영상으로 내보내고8개 시간대의 프레임으로 등장 순서와 이동을 확인했습니다.
- 지도 표식이 최고 별을 가리는 문제, 코인 입자가 숫자를 가리는 정지 화면, 주문표 배경과 도구 아이콘을 보정했습니다.
- 효과 줄이기 상태에서 별·점수·금액·다음 목표는 유지하고 비행·확대·흔들림을 제거했습니다.

## 구현 전인 부분

Figma의 모션 타임라인은 무음입니다. 영상은 실제 Figma 렌더에 임시 합성 사운드를 합친 검토본이며, 최종 음악·Foley는 별도 제작합니다. 음원의 파일 형식·길이·피크는 확인했지만 최종 청음·믹싱 승인을 대신하지 않습니다.

공방·캐릭터는 A02 PNG입니다. 걷기·손동작·표정 등 최종3D 애니메이션, 실제 기기의 진동·60fps 성능, MAX·계정·저장 서비스는 구현 전입니다. 프로토타입의 시간·점수·재화는 상태별 예시이며 실제 게임처럼 누적 계산되는 것은 아닙니다.

A03 타이틀과 설정의 계정·백업은 기존 A02 로그인 프로토타입을 별도로 엽니다. 변경하지 않은 계정·클라우드 충돌·광고 미충족·저장 예외는 A02/v2.0 정의를 유지합니다. A03만으로 모든 서비스 기능이 새로 구현된 것은 아닙니다.

다음 확인은 실제 플레이 테스트입니다. **소리 없이도 행동·진행·완료를 구분하는지, 실패 이유와 다음 행동을 설명할 수 있는지, 다시 도전하고 싶은지**를 확인해야 합니다. 만족도나 유지율이 개선됐다는 수치는 아직 없습니다.
